# Contributing to Sinjal

Sinjal is an **author-driven open-source project**.

## Issues

Bug reports and focused feature suggestions are welcome.

Use the issue templates and include enough detail to reproduce bugs.

There is no response-time or implementation guarantee.

## Pull requests

**Pull requests are intentionally not accepted.**

The project keeps a single-author/maintainer implementation model to preserve architectural consistency and avoid low-signal automated contribution volume.

Forks are welcome under the MIT license.

## AI-generated pull requests

Automated or substantially AI-generated pull requests are not accepted.

This policy is not a statement against AI-assisted development. Sinjal itself may be developed with coding agents. The restriction exists because the maintainer wants architectural control and does not want to spend time reviewing unsolicited generated patches.

## Security issues

Do not publish sensitive vulnerabilities as public issues. Follow `SECURITY.md`.
